MULTIGRID: standalone web app arranging user-supplied streams (Twitch, YouTube, Kick, .m3u8, iframe code, any other link) in a CSS Grid with presets, custom dividers/corner resize, saved layouts in localStorage. Shipped Nov 4, 2026. Live: https://thisiseames.github.io/multigrid/ . Source: /Volumes/Seagate/Claude/multigrid (no local git; repo github.com/thisiseames/multigrid, public). Plain ES modules, no build step. $0 on GitHub Pages. Started from his pasted spec.

**Deploy:** no GitHub login on this machine, so upload through his signed-in Chrome at `github.com/thisiseames/multigrid/upload/main[/folder]`, one folder per upload, then Commit. exFAT makes `._*` files: never upload them.

**Testing:** `tests/*.test.mjs` run with `~/.local/node22/bin/node --test`. Preview server `tests/serve.mjs` (launch.json "multigrid"; python http.server can't start on this drive). The built-in browser pane shows third-party frames black, so it can't judge playback. Selenium Chrome with a throwaway profile works, and can switch into cross-origin frames to read the real video state. Automated Safari refuses every video play(), even on a bare page, so it only proves layout.

**Hard-won rule: nothing may overlap a Twitch player.** Twitch won't autoplay, and pauses and stays paused, if any box covers it, even an invisible `pointer-events: none` layer. So: `.edit-layer` is `display: contents`; custom mode tiles have wider gaps and a footer so handles sit beside the video; notes live in the top bar; anything that must cover (menus, dialogs, drags) goes through `coverage` in ui.js, which restarts Twitch afterwards. YouTube's terms also ban overlays, hence the strip above each tile.

**No sandbox on other-site tiles (his go, Nov 5).** I shipped one; a player he pasted showed "SANDBOX DETECTED" and wouldn't play. Removed for all of them. The trade he accepted: a pasted site could redirect the page or open pop-ups.
